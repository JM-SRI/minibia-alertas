# minibia-alertas

Alertas con pitido para Minibia (solo leen la pantalla y pitan; no tocan el juego).

- `alertas.js`: el código de las alertas. **La extensión se lo baja de aquí cada 3 min**: cambiar este archivo = actualizar a JM sin que haga nada.
- `extension/`: la extensión de Chrome (se instala una vez con "Cargar descomprimida").
